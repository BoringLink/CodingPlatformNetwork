## 项目管理

### 前端

- 使用 pnpm 作为包管理器
- 使用 vite 作为构建工具

### 后端

- 使用 NestJS 作为后端框架
- 使用 Prisma 作为数据库 ORM
- 使用 SQL Server 作为数据库

### git

- 使用 git 作为版本控制工具
- 每个功能点都对应一个 git 分支
- 提交信息使用中文
- 每个分支都对应一个 PR

## 参考资料

- Real Data目录存储了需要存储到数据库的真实数据
- .trae/documents目录存储了后端和数据库的设计方案
