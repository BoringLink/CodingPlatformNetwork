# 交互网络可视化系统全面测试计划

## 1. 测试环境搭建

### 1.1 前端环境
- 启动前端开发服务器：`cd frontend && pnpm run dev`
- 访问地址：`http://localhost:5173`
- 确保依赖安装完整：`cd frontend && pnpm install`

### 1.2 后端环境
- 启动后端开发服务器：`cd backend && pnpm run start:dev`
- API地址：`http://localhost:3000/api/v1`
- 确保依赖安装完整：`cd backend && pnpm install`

### 1.3 数据库环境
- 确保SQL Server数据库连接正常
- 准备测试数据
- 确保数据库迁移完成：`cd backend && npx prisma migrate dev`

### 1.4 测试工具安装
- 前端测试工具：`cd frontend && pnpm install --save-dev jest @types/jest ts-jest @testing-library/react @testing-library/jest-dom`
- 后端测试工具：`cd backend && pnpm install --save-dev jest @types/jest ts-jest supertest`
- 端到端测试工具：`pnpm install --save-dev @playwright/test && npx playwright install`
